SAD Pre-Screening Run

An agent takes over a research coordinator's weekly pre-screening for NCT07347678 (SAD cohort). Deterministic rules decide everything a rule can decide; the agent handles what rules cannot read: missing results, free-text history, conflicting results and evidence for the investigator. Synthetic data only; no patient is contacted.

2 · Agent

What the agent does that rules cannot

Strands Agents on Amazon Bedrock (Amazon Nova 2 Lite). The model reads, searches and explains; code compares numbers, applies windows and makes the call. Every step is traced.

The model does

  • Chooses equivalent codes and re-queries when a result is missing
  • Reads patients' own words (smoking, drug history) into facts, each with a quote
  • Decides which liver and kidney records to look up for the investigator
  • Explains conflicting results and what to check
  • Labels changed criteria as substantive, wording or ambiguous

Code does

  • Every numeric comparison and time window, with Ming's thresholds
  • Checks each quote really occurs in the source; drops it otherwise
  • Drug classes from the NLM RxNav terminology, never the model's memory
  • Scans the text for drugs the model failed to report
  • Decides whether a conflict changes the outcome; flags abnormal labs from reference ranges

Amendment monitoring

When the criteria change

The fetched criteria are compared with the last snapshot. Each changed item is classified by the model; only substantive changes trigger a re-screen with the amended rules (an engineering sample amendment here: SAD LDL-C threshold 70 → 100 mg/dL, HbA1c line reworded).
